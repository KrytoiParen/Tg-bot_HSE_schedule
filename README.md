# Расписание ВШЭ НН

Telegram-бот: утром присылает расписание на сегодня, каждый час проверяет изменения и сообщает, что удалено и добавлено. Каждый студент выбирает свою учебную группу и отдельно группу английского.

Расписание приходит rich-сообщением Telegram: заголовок с группой и датой, таблица «Время · Занятие · Где», преподаватель и полный адрес корпуса. Английский показывается как «Английский язык». Пометки о начале занятий, отменах и разовых заменах бот учитывает при составлении расписания, но скрывает из текста. Внизу остаётся время последней успешной проверки.

Используется метод [sendRichMessage](https://core.telegram.org/bots/api#sendrichmessage), который поддерживает установленный aiogram 3.31. Старые подписки и очередь сохраняются; после обновления кода перезапустите процесс бота. Уже отправленные сообщения останутся прежними.

## Запуск

Нужен Python 3.11 или новее.

```bash
cd "/Users/sheazure/Desktop/HSEschedule 2"
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Если `.env` ещё нет, скопируйте `.env.example` в `.env`. Укажите `BOT_TOKEN` из [BotFather](https://t.me/BotFather).

```bash
python main.py
```

В личном чате отправьте `/start`: бот спросит факультет, направление, курс, учебную группу и группу английского. Для английского второго курса нужны две группы: верхней и нижней недели. Если одинаковый номер встречается несколько раз, бот предложит выбрать уровень и преподавателя.

Рассылка по умолчанию приходит в 07:00 МСК. В `.env` можно изменить `MORNING`. Отдельный студент может задать своё время через `/time 08:00`.

Для рассылки процесс должен работать постоянно. При закрытии терминала или переходе компьютера в сон бот остановится. Для круглосуточной работы нужен включённый компьютер или сервер. Запускайте один экземпляр.

## Структура

Как в [autogiftsbot](https://github.com/sheazure/autogiftsbot): запуск отдельно, обработчики в `handlers`, клавиатуры и вспомогательные функции в своих файлах.

```text
main.py            запуск бота и фоновой задачи
config.py          настройки из .env
handlers/user.py   команды, кнопки и состояния настройки
keyboards.py       клавиатуры
utils.py           сообщения, проверка изменений и рассылка
messages.py        rich-таблицы и оформление расписания
database.py        функции для SQLite
schedule.py        чтение PDF, таблиц и дат занятий
logger.py          вывод ошибок и событий
```

База осталась в `data/bot.db`, существующие подписки сохраняются. Для переноса остановите бота и скопируйте папку `data`.

## Команды

| Команда | Действие |
| --- | --- |
| `/menu` | Меню с кнопками |
| `/start`, `/settings` | Выбрать направление и группу |
| `/today`, `/tomorrow`, `/week` | Сегодня, завтра, ближайшие 7 дней |
| `/english` | Изменить группы английского |
| `/time 07:00` | Время рассылки по Москве |
| `/status` | Последняя проверка |
| `/stop` | Отключить рассылку |
| `/cancel` | Отменить настройку |

## Проверки

```bash
python -m unittest discover -s tests -v
python main.py --check
```

Тесты работают без сети на сохранённых официальных таблицах. `--check` скачивает и разбирает все таблицы из [PDF ВШЭ](https://nnov.hse.ru/mirror/pubs/share/1200526994.pdf), токен для него не нужен.

PDF содержит ссылки на Google-таблицы. Первая подписка сохраняет исходное расписание, следующие проверки сравнивают занятия выбранной учебной группы и английского. Уведомления приходят подписавшимся студентам в личные чаты. Прошедшие занятия в сравнение не попадают.

После ошибки загрузки остаётся последняя проверенная версия. Неотправленные сообщения хранятся в SQLite до следующей попытки. Пропущенная утренняя рассылка отправляется в пределах двух часов; сообщения за прошлый день отбрасываются. Обычный перезапуск не повторяет рассылку. При аварийном завершении между отправкой в Telegram и записью результата в базу возможен повтор одного сообщения.

Особенности источников:

- Английский выбирается по точному номеру, направлению, уровню и преподавателю. Строки объединённых ячеек разбираются отдельно. Если пропустить выбор, эта часть английского не попадёт в расписание; добавить её можно через `/english`.
- В английском второго курса оставлен календарь 2025–2026. Если годы отличаются, бот берёт год и недели из основного расписания и предупреждает при настройке.
- У дизайна занятия читаются из видимого листа `Расписание`, срок модуля — из служебного листа курса.
- Для магистерского «Цифрового маркетинга» в PDF нет ссылки, поэтому это направление пока не включено в меню.

Если университет изменит формат таблиц, разбор может потребовать правки.
