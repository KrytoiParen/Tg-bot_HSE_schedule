# Telegram-бот расписания НИУ ВШЭ — Нижний Новгород

Учебный проект по дисциплине **«Технологии программирования»**.

Бот помогает студентам следить за расписанием в Telegram: показывает занятия выбранной группы, отправляет расписание на день и уведомляет об изменениях. Данные берутся из опубликованных университетом таблиц.

## Идея проекта

Расписание учебной группы и занятия по английскому могут находиться в разных таблицах. Чтобы узнать план на день, студенту приходится искать свою группу, учитывать даты занятий и проверять обновления.

Цель проекта — собрать нужную студенту информацию в одном личном чате и автоматизировать проверку изменений.

## Возможности

- **Личное расписание.** Выбор уровня обучения, факультета, направления, курса и учебной группы.
- **Отдельная настройка английского.** Выбор группы по номеру, уровню и преподавателю; учёт верхней и нижней недели, если такое разделение есть в источнике.
- **Просмотр занятий.** Расписание на сегодня, завтра или ближайшие семь дней.
- **Ежедневная рассылка.** Отправка расписания в выбранное время. По умолчанию — в 07:00 по Москве.
- **Уведомления об изменениях.** Проверка источников каждый час и сообщения о добавленных и удалённых занятиях только тем пользователям, чьё расписание изменилось.
- **Понятное оформление.** Таблица с временем, названием занятия, преподавателем, аудиторией и полным адресом корпуса, если эти сведения доступны в источнике.
- **Учёт примечаний.** Обработка дат начала и окончания занятий, отмен и разовых изменений времени или места проведения.
- **Сохранение данных.** Подписки, настройки, сохранённое расписание и очередь сообщений хранятся в SQLite и сохраняются после перезапуска.

## Как пользоваться

1. Открыть личный чат с ботом и отправить `/start`.
2. Выбрать уровень обучения, факультет, направление и курс.
3. Указать название или номер учебной группы.
4. Выбрать группу английского. Если номер пока неизвестен, этот шаг можно пропустить и вернуться к нему через `/english`.
5. При необходимости изменить время рассылки, например командой `/time 08:00`.

После настройки бот покажет расписание на сегодня. Дальше занятия можно смотреть через команды или кнопки меню, а ежедневные сообщения и уведомления об изменениях будут приходить автоматически.

Номер группы английского может отличаться от номера учебной группы. Если выбор английского пропущен, соответствующие занятия не включаются в личное расписание.

## Команды

| Команда | Что делает |
| --- | --- |
| `/start` | Начать настройку подписки |
| `/menu` | Открыть меню с кнопками |
| `/settings` | Изменить направление и учебную группу |
| `/today` | Показать расписание на сегодня |
| `/tomorrow` | Показать расписание на завтра |
| `/week` | Показать расписание на ближайшие семь дней |
| `/english` | Изменить группы английского |
| `/time 08:00` | Установить время ежедневной рассылки по Москве |
| `/status` | Показать состояние подписки и время последней успешной проверки |
| `/stop` | Отключить рассылку |
| `/cancel` | Отменить текущую настройку, сохранив существующую подписку |
| `/help` | Показать справку по командам |

## Как работает бот

1. Из [официального PDF-указателя НИУ ВШЭ](https://nnov.hse.ru/mirror/pubs/share/1200526994.pdf) извлекаются ссылки на Google-таблицы с расписанием.
2. Таблицы загружаются в формате XLSX. Бот разбирает группы, занятия, даты, аудитории и примечания.
3. На основе выбранной учебной группы и групп английского составляется личное расписание пользователя.
4. При очередной проверке новая версия сравнивается с сохранённой. Изменения за прошедшие дни не включаются в уведомления.
5. Уведомления записываются в очередь и отправляются в личный чат. Отдельно формируется ежедневное сообщение с расписанием на текущий день.

Если источник временно недоступен, бот сохраняет последнюю успешно полученную версию и предупреждает об ошибке обновления. При временной ошибке отправки сообщение остаётся в очереди для повторной попытки.

## Структура проекта

```text
├── main.py                     # Точка входа и запуск фоновой задачи
├── config.py                   # Настройки и часовой пояс
├── handlers/
│   └── user.py                 # Команды и пошаговая настройка подписки
├── keyboards.py                # Кнопки меню и выбора групп
├── schedule.py                 # Загрузка и разбор источников расписания
├── messages.py                 # Оформление расписания в таблицы
├── utils.py                    # Сравнение расписаний, рассылка и отправка сообщений
├── database.py                 # Работа с SQLite
├── logger.py                   # Журналирование событий и ошибок
├── requirements.txt            # Зависимости проекта
└── tests/                      # Автоматические тесты и примеры исходных данных
```

Код разделён по задачам: обработчики отвечают за диалог с пользователем, модуль расписания — за данные, а отдельные модули — за хранение и отправку сообщений. Пошаговая настройка реализована через механизм состояний FSM в aiogram.

## Тестирование

В проекте предусмотрены автоматические проверки:

- разбора учебных групп и групп английского, включая объединённые ячейки;
- дат занятий, отмен и разовых замен аудитории или корпуса;
- оформления таблиц и разделения длинных сообщений;
- сравнения версий расписания и выбора получателей уведомлений;
- сохранения подписок и работы очереди после перезапуска;
- прохождения диалога настройки через обработчики aiogram.

Тесты используют сохранённые примеры источников, временную базу данных и подмену ответов внешних сервисов. Для их запуска не нужен токен Telegram:

```bash
python -m unittest discover -s tests -v
```

## Особенности работы

- Все настройки времени и ежедневная рассылка используют московский часовой пояс.
- Бот показывает данные из опубликованных источников; задержки и ошибки в самих таблицах могут отражаться в расписании.
- Набор доступных направлений и групп зависит от ссылок в PDF-указателе и содержимого таблиц.
- При изменении структуры университетских таблиц может потребоваться доработка их разбора.
- Автоматическая рассылка и проверка изменений выполняются, пока бот работает.
